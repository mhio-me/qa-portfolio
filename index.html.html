Sample Work

Recreated QA artifacts from the Marlboro raffle project — bug reports, test cases, and automation scripts.

BUG-1024

Daily UPC code entry limit not enforced

High

Staging · Chrome 126, Windows 11

Open
  1. Log in to the raffle web app with a valid account.
  2. Enter a valid UPC code from a Marlboro pack via the entry form.
  3. Repeat step 2 until reaching the account's daily entry limit (5 codes/day).
  4. Submit one additional valid, unused UPC code beyond the daily limit.

Entry is rejected with a message such as "Daily entry limit reached — try again tomorrow," and the code is not counted toward the raffle.

The additional UPC code is accepted and counted as a valid entry, allowing the account to exceed the stated daily limit.

TC-215

Verify a redeemed winning UPC code cannot be claimed twice

Pass

Prize Distribution

UPC code has already won and is marked "Redeemed" in the system.

  1. Navigate to the prize redemption page.
  2. Enter the already-redeemed UPC code.
  3. Submit for redemption.

System displays "This prize has already been claimed" and does not process a second payout.

SCRIPT-003

Automated regression check — daily UPC entry limit

Playwright · Selenium IDE

Two ways I'd cover the BUG-1024 scenario going forward: a scripted Playwright test for CI, and a recorded Selenium IDE case for quick manual re-checks.

Playwright (TypeScript)
upcDailyLimit.spec.ts 
import { test, expect } from '@playwright/test'; test('blocks entry once daily UPC limit is reached', async ({ page }) => {    await page.goto('/raffle');     for (let i = 1; i <= 5; i++) {        await page.fill('#upc-input', `UPC-000${i}`);        await page.click('#submit-entry');        await expect(page.locator('.entry-success')).toBeVisible();    }     // 6th code should exceed the daily limit    await page.fill('#upc-input', 'UPC-0006');    await page.click('#submit-entry');     await expect(page.locator('.limit-error')).toHaveText(        'Daily entry limit reached'    );});
